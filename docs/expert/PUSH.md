# Как выложить в NH3Bench

Пушить нужно вам: у меня нет доступа к вашему GitHub. Ниже — всё готовое.

## Что в папке

```
docs/
  index.html         титульная страница со ссылками на оба материала
  expert-guide.html  описание имитатора и пяти задач (было: NH3Ops-описание-для-эксперта.html)
  trainer.html       тренажёр (было: NH3Ops-тренажёр-эксперта.html)
  .nojekyll          чтобы GitHub Pages отдавал файлы как есть
```

Имена переименованы в латиницу: кириллические имена файлов в URL превращаются в
процентные последовательности и ломаются при копировании ссылки в письмо.
Содержимое и заголовки внутри — на русском, как было.

Папка называется `docs/`, потому что GitHub Pages умеет раздавать её напрямую с
ветки `main` без отдельной ветки `gh-pages`.

## Команды

```bash
git clone https://github.com/nicl-nno/NH3Bench.git
cd NH3Bench
# скопировать сюда папку docs/ из этого архива
git add docs
git commit -m "Материалы для экспертной проверки: описание задач и тренажёр"
git push origin main
```

Если репозиторий ещё пустой, `main` может называться `master` — посмотрите
`git branch` после клонирования. Если репозитория ещё нет, создайте его на
GitHub (публичным, иначе Pages потребует платный тариф) и повторите.

## Включить Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка
`/docs` → Save. Через минуту-две поднимется:

```
https://nicl-nno.github.io/NH3Bench/
```

Эту ссылку и отправляйте эксперту — с неё открываются оба материала.

## Почему тренажёр нельзя просто скачать и открыть

Он поднимает Web Worker и исполняет в нём настоящий расчётный код имитатора
через Pyodide. При открытии файла с диска (`file://`) Chrome блокирует создание
worker'а из blob — страница повиснет на загрузке. Нужен http(s): либо Pages,
либо локально:

```bash
cd docs && python3 -m http.server 8000
# http://localhost:8000/
```

Firefox с `file://` обычно справляется, но полагаться на это не стоит.

## Размеры

`expert-guide.html` — 768 КБ, `trainer.html` — 443 КБ. Оба файла автономны:
внутри уже лежат все картинки, стили, скрипты и исходники имитатора в base64.
Внешне грузится только Pyodide с CDN при запуске тренажёра.

## Если материалы обновятся

Оба файла — сборочные артефакты, править их руками не нужно. Пересборка из
основного репозитория проекта:

```bash
python3 viz/expert_data.py && python3 viz/expert_figs.py && python3 viz/build_expert_doc.py
python3 trainer/build_trainer.py
```

Затем переименовать полученные файлы в `expert-guide.html` и `trainer.html` и
закоммитить. Важно: если менялась калибровка задач, в тренажёре нужно обновить
таблицу опорных операторов (словарь `REF` в `trainer/build_trainer.py`), иначе
эксперту покажут устаревшие эталонные исходы.
